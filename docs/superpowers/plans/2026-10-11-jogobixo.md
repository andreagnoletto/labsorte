# Jogo do Bixo — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Simulador educativo em Django (fichas fictícias) de jogo do bicho, roleta, caça-níquel e dado, expondo a matemática de cada jogo.

**Architecture:** Projeto `config` gerado por `django-admin startproject`, apps `core`, `wallet`, `bicho`, `casino`, `learn` gerados por `startapp`. Toda movimentação de fichas passa por `wallet.services` dentro de `transaction.atomic()`; motores de jogo são funções puras testadas isoladamente; views finas em cima dos serviços.

**Tech Stack:** Python 3.12, Django 6.0, SQLite, templates server-side, CSS próprio, JS mínimo. Ambiente com `uv venv`.

**Spec:** `docs/superpowers/specs/2026-10-11-jogobixo-design.md`

## Global Constraints

- Estrutura SEMPRE gerada pela CLI (`django-admin startproject config .`, `python manage.py startapp <app>`), nunca criada à mão.
- Sem dinheiro real, sem pagamentos; moeda "fichas" (F$). Bônus inicial 1000; recarga 1000 (contada em `Wallet.recharges`).
- Aposta mínima 1, máxima 500 fichas.
- UI em pt-BR; identificadores em inglês com termos de domínio preservados.
- Multiplicadores bicho: Grupo 18, Dezena 60, Centena 600, Milhar 4000; "1º ao 5º" paga `mult/5` por prêmio acertado.
- Roleta europeia 37 casas: número 36x, chances simples 2x, dúzia/coluna 3x.
- Caça-níquel: rolos de 20 símbolos (6 cereja, 5 limão, 4 laranja, 2 sino, 1 estrela, 1 sete, 1 diamante); trincas 5/8/15/25/60/150/1000; exatamente duas cerejas 2x. RTP = 7474/8000.
- Dado: 6 faces, paga 5x.
- Sem git (usuário não pediu).

from decimal import Decimal
from django.contrib.auth import get_user_model
from django.test import TestCase
from wallet import services
from wallet.models import Transaction

class WalletServiceTests(TestCase):
    def setUp(self):
        self.user = get_user_model().objects.create_user("ana", password="x")

    def test_get_wallet_creates_with_initial_bonus(self):
        wallet = services.get_wallet(self.user)
        self.assertEqual(wallet.balance, services.INITIAL_BONUS)
        self.assertEqual(wallet.transactions.count(), 1)
        self.assertEqual(wallet.recharges, 0)
        services.get_wallet(self.user)  # segunda chamada não duplica bônus
        self.assertEqual(wallet.transactions.count(), 1)

    def test_debit_and_credit_update_balance_and_ledger(self):
        wallet = services.get_wallet(self.user)
        tx = services.debit(wallet, Decimal("10"), Transaction.Game.DICE, "aposta")
        self.assertEqual(tx.amount, Decimal("-10"))
        self.assertEqual(tx.balance_after, Decimal("990"))
        services.credit(wallet, Decimal("50"), Transaction.Kind.PAYOUT, Transaction.Game.DICE, "prêmio")
        wallet.refresh_from_db()
        self.assertEqual(wallet.balance, Decimal("1040"))

    def test_debit_insufficient_funds_changes_nothing(self):
        wallet = services.get_wallet(self.user)
        with self.assertRaises(services.InsufficientFunds):
            services.debit(wallet, Decimal("5000"), Transaction.Game.DICE, "x")
        wallet.refresh_from_db()
        self.assertEqual(wallet.balance, services.INITIAL_BONUS)
        self.assertEqual(wallet.transactions.count(), 1)

    def test_recharge_counts(self):
        wallet = services.get_wallet(self.user)
        services.recharge(wallet)
        wallet.refresh_from_db()
        self.assertEqual(wallet.recharges, 1)
        self.assertEqual(wallet.balance, services.INITIAL_BONUS + services.RECHARGE_AMOUNT)

    def test_summary(self):
        wallet = services.get_wallet(self.user)
        services.debit(wallet, Decimal("10"), Transaction.Game.DICE, "a")
        services.debit(wallet, Decimal("20"), Transaction.Game.SLOTS, "b")
        services.credit(wallet, Decimal("15"), Transaction.Kind.PAYOUT, Transaction.Game.DICE, "p")
        s = services.summary(wallet)
        self.assertEqual(s["staked"], Decimal("30"))
        self.assertEqual(s["won"], Decimal("15"))
        self.assertEqual(s["net"], Decimal("-15"))
        self.assertEqual(s["bets"], 2)
        self.assertEqual(s["per_game"]["DICE"]["net"], Decimal("5"))

from django.test import SimpleTestCase
from casino import dice, roulette, slots

class RouletteTests(SimpleTestCase):
    def test_colors(self):
        self.assertEqual(roulette.color(0), "verde"); self.assertEqual(roulette.color(1), "vermelho"); self.assertEqual(roulette.color(2), "preto")
    def test_wins(self):
        B = roulette.BetType
        self.assertTrue(roulette.wins(B.NUMBER, "17", 17)); self.assertFalse(roulette.wins(B.NUMBER, "17", 18))
        self.assertTrue(roulette.wins(B.RED, "", 1)); self.assertFalse(roulette.wins(B.RED, "", 0)); self.assertFalse(roulette.wins(B.BLACK, "", 0))
        self.assertTrue(roulette.wins(B.EVEN, "", 2)); self.assertFalse(roulette.wins(B.EVEN, "", 0))
        self.assertTrue(roulette.wins(B.LOW, "", 18)); self.assertTrue(roulette.wins(B.HIGH, "", 19))
        self.assertTrue(roulette.wins(B.DOZEN, "2", 13)); self.assertFalse(roulette.wins(B.DOZEN, "2", 25))
        self.assertTrue(roulette.wins(B.COLUMN, "1", 34)); self.assertTrue(roulette.wins(B.COLUMN, "3", 36)); self.assertFalse(roulette.wins(B.COLUMN, "3", 0))
